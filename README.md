# Kurtis Papple Portfolio

This repository publishes the portfolio at https://kurtisstirling.github.io/portfolio/ using GitHub Pages. The case studies are Markdown pages under `items/`, with their images alongside them. Edit the Markdown and push to `main` to update the site.

The source copy is `~/career/hunting/portfolio/`. This public repository contains only material intended for the portfolio; review additions before publishing them.

Use WebP for portfolio images. Resize an image to a 2,400-pixel longest side when its original longest side exceeds 3,200 pixels; this keeps large diagrams readable without making mobile pages heavy.
